# 怎么新建一个任务

每个交给 Codex 的任务，建议在 `tasks/` 下单独建一个目录。

## 步骤

1. 复制 `_template` 目录，改名为你的任务名（小写、连字符分隔，例如 `rename-pdf`）。
2. 在里面的 `brief.md` 写清：要做什么、输入是什么、期望输出是什么、有没有约束（语言 / 框架 / 不做什么）。
3. 把相关素材（样本文件、截图、参考链接）也放这个目录。
4. 让 Codex 连仓库并指向这个任务目录。

## 命名示例

- `tasks/rename-pdf/` — 批量重命名 PDF
- `tasks/quiz-to-html/` — 把题库转成网页
- `tasks/auto-backup/` — 写个自动备份脚本

> 任务做完后，目录可保留当存档，也可合并进 `src/`（可复用代码）。
